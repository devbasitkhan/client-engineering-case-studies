## Evidence & Claim Discipline

These documents distinguish between:

- **delivered engagement status** — based on the actual client work
- **documented project scope** — reconstructed from retained project briefs, questionnaires and proposals
- **implementation claims** — included only where retained material supports them

Proposal-stage technology options are not automatically presented as confirmed production architecture.

## Commercial Work & Confidentiality

These were paid client engagements. Public documentation is intentionally sanitized and excludes client credentials, CRM contact data, phone lists, private sales scripts, API keys, customer information, production tokens, proprietary workflow exports and confidential business metrics.

Where an exact production detail cannot be verified from retained project material, the case study states the requirement or design scope rather than inventing specifics.
